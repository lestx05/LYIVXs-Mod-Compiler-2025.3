# Contributing

Thanks for helping improve this fork.

## Scope

This project is focused on:

- MCreator 2025.3
- Forge 1.20.1 workspaces
- The **Use Compiled Mods** External API workflow

Please do not add support claims for other versions unless they are tested.

## Good issues include

- MCreator version
- Forge generator version
- Full Gradle error or log output
- Exact jar filenames inside `compile-mods-1.20.1`
- Steps to reproduce

## Pull requests

Keep changes small and focused.

Do not remove credits for LYIVX, Tarantel, or referenced forks.
