# Security Policy

## Supported versions

This fork currently supports only:

- MCreator 2025.3
- Forge 1.20.1 workspaces

## Reporting security issues

Do not use this plugin with untrusted mod jars.

Compiled mod jars can execute code when loaded by the Minecraft/Forge runtime. Only use jars from sources you trust.

If you find a security issue in this repository, open an issue with clear reproduction steps and avoid sharing harmful payloads.
