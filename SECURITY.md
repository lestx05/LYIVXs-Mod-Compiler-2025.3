# Security Policy

## Supported versions

This fork currently supports only:

- MCreator 2025.3
- Forge 1.20.1 workspaces

## Reporting security issues

Do not use this plugin with untrusted mod JAR files.

Compiled mod JAR files can execute code when loaded by the Minecraft/Forge runtime. Only use JAR files from sources you trust.

If a security issue involves a harmful payload or private exploit details, do not post it publicly. Use GitHub private vulnerability reporting if it is available, or contact the maintainer privately.

For non-sensitive security hardening, open an issue with clear reproduction steps and avoid sharing harmful payloads.
